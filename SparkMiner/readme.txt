SparkMiner
	https://github.com/SneezeGUI/SparkMiner
Use Quick Start Option 1 Launcher + SD Card.

Step #1, in the Launcher Web Flasher for the device choose "CYD-2432W328C Inverted Colors and 2.4in (Capacitive)(OTA)" and the flash.

Step #3, power on and choose "Launcher", "SD", and the Step #2 .bin file name (or scroll down and then select).  Choose to "Install" the FW.  Later to do a SparkMiner firmware update (new .bin file or new .json file), on the boot screen choose "Launcher" and then choose the red text/square for the FW that was installed and choose to delete the firmware.  Reboot and to a SD install again.
